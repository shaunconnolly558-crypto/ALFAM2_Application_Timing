# Output Directory

This directory contains the outputs generated by the analysis pipeline.

The full Monte Carlo simulation dataset (`mc_results_master.csv`) is archived separately on Zenodo to ensure long-term preservation and reproducibility.

**Monte Carlo simulation dataset:**
https://doi.org/10.5281/zenodo.21511498

The Zenodo archive contains the master dataset generated from the Monte Carlo simulations described in the accompanying manuscript.

The analysis scripts in `R/` can be used to reproduce the downstream analysis and generate the tables and figures reported in the manuscript.

Large generated output files are not stored directly in this GitHub repository.
